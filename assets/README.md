# Brand assets

Copied from the Multiplying Panda Flutter app on 27 November 2026:

- `app-icon.png`: the existing 1024 × 1024 iOS app icon, unchanged.
- `practice.png`: actual English practice-screen capture, with the sound control enabled, from `artifacts/practice-sound/captured/ios/en/practice-sound-on.png`.
- `fonts/NunitoText.ttf`: the app's bundled variable Nunito text font. Its numeric glyphs intentionally use the browser's system fallback, consistent with the app's separation of text and numbers.
- `fonts/Nunito-OFL.txt`: the font's SIL Open Font License.

No external asset requests are made by the website. App artwork is not licensed for unrelated reuse by this repository.
